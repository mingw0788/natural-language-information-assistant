# 自然语言信息采集助手

Windows 本地单用户信息采集工具。应用通过浏览器界面运行，只监听本机回环地址。

## 开发启动

需要 Python 3.11。PowerShell 中执行：

```powershell
.\run.ps1
```

脚本会在项目目录创建 `.venv`、安装项目依赖并启动本地服务。浏览器访问启动输出中的地址。按 `Ctrl+C` 停止。

首版需要你在“设置”中分别配置搜索服务与模型服务。未配置的服务不会被调用；可以先用网址或粘贴文字开始本地处理。密钥保存在 Windows 凭据管理器中，不写入项目数据库。

## 数据位置

应用数据保存在当前用户本地应用数据目录；不会扫描其他文件夹。不要把 `.env` 或密钥提交到 Git。

首版覆盖范围与限制以工作区根目录的《自然语言信息采集助手：需求分析》和验收表为准。
