# 自然语言信息采集助手

Windows 本地单用户应用。用中文或英文描述查询目标，检查整理后的搜索词，再采集公开网页、文字 PDF 或你粘贴的材料。默认不需要 API、密钥或云模型；应用会展示实际读取的网页原文、出处、运行进度和任务版本。

## 启动

需要 64 位 Python 3.11 和可用网络以安装 Python 依赖。PowerShell 执行：

```powershell
.\run.ps1
```

脚本会创建项目内 `.venv`、按 `requirements.lock` 安装固定版本并安装本地应用。动态页面读取优先使用已有的 Playwright Chromium，再尝试本机 Microsoft Edge。两者都不可用时仍直接启动，读取静态页面，不会自动下载约 200 MiB 的 Chromium。服务只绑定 `127.0.0.1:8000`；浏览器打开启动输出中的地址，按 `Ctrl+C` 停止。

需要读取依赖浏览器渲染的页面时，可以自行选择安装 Chromium，再重新启动应用：

```powershell
.\.venv\Scripts\python.exe -m playwright install chromium
```

依赖已经安装好时，也可直接启动，跳过安装检查：

```powershell
.\.venv\Scripts\python.exe -m uvicorn info_assistant.main:app --host 127.0.0.1 --port 8000
```

## 开始使用

1. 像平常提问一样写下目标和条件，不必先整理成搜索关键词；应用会展示整理后的搜索词。
2. 核对任务摘要、搜索词、字段、必要条件、默认假设和数据流，再开始采集。
3. 默认使用普通网页搜索，无需注册或填写密钥。搜索网站默认为必应，也可在“设置”中切换为国内的百度。网站出现安全验证或访问限制时，本轮搜索会停止并显示原因，可补充具体网址继续采集；不会绕过验证。
4. 默认使用本地读取，不调用云模型。结果区会显示实际抓取的网页原文片段和链接；即使没有提取出结构化字段，也可以查看来源。直接提供网址或粘贴文字时，会先处理这些材料。
5. 本地任务解析与提取采用有限规则，不具备完整语言模型的复杂理解能力。目前主要从明确的“字段：值”格式提取；复杂字段可能为空或待核查。需要模型辅助时，可选国内智谱免费模型或自定义服务，配置不是启动条件。
6. 运行中可暂停、恢复或停止。有结构化结果时，可筛选、修正字段、撤销修正，并导出 CSV、XLSX、JSON、Markdown 或纯文本。

搜索摘要只用于发现来源，不作为证据。原文卡片展示实际读取的来源内容；结构化结果保留对应摘录。条件不明、字段缺失、来源冲突或原始快照过期时会显示待核查或证据失效状态。用户修正会单独标记，不覆盖原始来源记录。

## 可选国内服务

默认模式无需以下服务。设置中仍提供高级选项，供需要服务接口或模型提取时自行选择：

- 百度搜索 API 当前提供每日 100 次免费调用，仍需申请 API Key。账户实际余量、开通要求和超额计费以百度控制台为准；只使用免费额度时请勿启用超额后付费。参见[百度官方说明](https://ai.baidu.com/ai-doc/AppBuilder/pmaxd1hvy)。
- 智谱 `glm-4.7-flash` 当前输入、输出免费，仍需平台账户和 API Key；速率与免费政策以官方账户规则为准。应用提供预设地址和模型名，参见[智谱免费模型说明](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)。
- 也可使用自定义模型兼容接口；本地运行的模型可填写本机地址，其安装与硬件配置不包含在本应用中。

免费政策可能调整，不代表无限调用。切换搜索服务不会复用其他服务的密钥；切换模型服务地址需要提供对应的新密钥。

## 外部服务与隐私

- 默认搜索仍需要联网：开始任务后，整理后的搜索词会发送到所选普通搜索网站，随后读取结果链接中的来源页面。无需密钥不等于离线搜索。
- 默认不调用云模型，正文和结果在本机处理。只有自行配置并使用模型提取后，任务文字和选择读取的来源正文才会发送到该模型服务；选用搜索 API 时，搜索词会发送到所选服务。
- 可选的搜索与模型 API 密钥保存在 Windows 凭据管理器，不写入 SQLite、页面响应、导出或日志。应用不会自动读取环境变量中的密钥。
- 模型服务地址要求 HTTPS；只有本机地址允许 HTTP。模型只返回结构化数据，不拥有浏览器操作、文件或任意工具权限。
- 网页内容始终视作不可信数据。应用不登录网站、不绕过验证码或访问控制、不点击网页按钮、不无限滚动、不扫描本机文件夹。
- 应用关闭了跨域访问，写操作校验本机 Host、Origin 和 CSRF 令牌。服务只监听回环地址。

## 采集边界和额度

- 仅支持公开 HTTP(S) 页面、公开文字 PDF 和用户主动粘贴的文字；不支持登录后内容、图片 OCR、音视频或批量本机文件。
- 来源网页抓取会检查 robots 规则并限制访问节奏。普通搜索页采用用户发起的查询读取模式，不保证搜索网站允许自动读取其搜索路径；出现验证、拒绝访问或页面结构不兼容时停止并说明原因，可改为提供具体网址。不承诺所有网站均可读取。
- 校验 DNS、重定向和浏览器子请求，拒绝本机、私网、链路本地和保留地址。
- 单个网页正文最多 10 MiB；PDF 最多 20 MiB、200 页，只提取可选择的文字。扫描版 PDF 会说明没有 OCR。
- 单个来源最多读取 5 页；一次运行最多 100 次文档读取和 20 次动态浏览器读取。
- 每轮最多 12 次搜索（首轮发现最多 8 个来源，最多补搜两轮、每轮最多 2 次），每日最多 60 次；模型每轮最多 40 次、每日最多 200 次。
- 输入 Token 每轮最多 120,000、每日最多 600,000；输出 Token 每轮最多 20,000、每日最多 100,000。计数按提供方 usage 或保守预留显示；服务未提供可信价格上界时不承诺精确费用封顶。
- 同一时刻最多一个运行；每轮主动运行最多 15 分钟，每天最多启动 20 轮。暂停、恢复和程序中断不会重置额度或时间。
- 来源失败时其他来源仍可继续；达到额度或时间上限会保存已有结果并标记为部分完成。中断时在途请求按已使用额度保留，结果未知的请求不会自动重新派发。

## 本机数据、备份与删除

数据库和来源快照位于：

```text
%LOCALAPPDATA%\NaturalLanguageInformationAssistant\assistant.sqlite3
```

应用默认保留原始来源快照 30 天，结果和必要摘录 180 天。原始快照清理后，摘录和来源链接可继续查看，但结果会标记为“证据已失效”，无法重新定位到完整原文。历史页支持删除任务及全部结果；任务页也可只清理原文并保留派生结果。备份前先停止应用，再复制整个数据目录；导出文件由浏览器下载到你的下载目录。

依赖固定版本记录在 `requirements.lock`。更新代码前备份本机数据目录；数据库启动时会按编号执行一次性迁移。

## 开发与验证

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check src tests
```

测试使用假搜索/模型服务、本地 HTTP 夹具、真实公开搜索页的保存样本和临时 SQLite；不会调用付费搜索或模型服务。覆盖免密钥设置、无模型时来源原文展示、验证码停止和页面内容安全展示。保存样本不代表网站未来页面始终兼容。浏览器集成测试需要本机 Microsoft Edge，或自行先运行 `python -m playwright install chromium`。
