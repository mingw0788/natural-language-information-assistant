# 自然语言信息采集助手

Windows 本地单用户应用。用中文或英文描述查询目标，检查系统对任务的理解，再采集公开网页、文字 PDF 或你粘贴的材料。结果逐步显示，并保留原文摘录、来源链接、运行进度和任务版本。

## 启动

需要 64 位 Python 3.11 和可用网络以安装 Python 依赖。PowerShell 执行：

```powershell
.\run.ps1
```

脚本会创建项目内 `.venv`、按 `requirements.lock` 安装固定版本并安装本地应用。动态页面读取优先使用 Playwright Chromium；若未安装，会尝试使用本机 Microsoft Edge；两者都不可用时才尝试下载 Playwright Chromium（约 200 MiB）。浏览器不可用或下载失败时应用仍会启动，动态页面回退到静态正文。服务只绑定 `127.0.0.1:8000`；浏览器打开启动输出中的地址，按 `Ctrl+C` 停止。

## 开始使用

1. 输入目标和条件，选择“检查任务条件”。
2. 核对任务摘要、字段、必要条件、默认假设和数据流。
3. 有直链或粘贴文字时可以本地开始处理。没有指定来源时，需先在“设置”中配置 Brave Search 密钥。
4. 模型服务用于结构化提取。未配置模型时，应用只会使用明确的“字段：值”格式做本机提取；其余结果可能为空或待核查。
5. 运行中可暂停、恢复或停止；可筛选结果、修正字段、撤销修正，并导出 CSV、XLSX、JSON、Markdown 或纯文本。

搜索摘要只用于发现来源，不作为证据。正式结果会显示来源摘录；条件不明、字段缺失、来源冲突或原始快照过期时会显示待核查或证据失效状态。用户修正会单独标记，不覆盖原始来源记录。

## 外部服务与隐私

- 搜索与模型服务默认不调用。只有你在设置里填写服务信息，并开始需要该能力的任务后，相关请求才会发送。
- 搜索词会发送给已配置的搜索服务；任务文字和选择读取的来源正文会发送给已配置的模型服务。直接网址和粘贴材料在没有模型服务时可在本机处理。
- Brave Search API 密钥、模型服务密钥保存在 Windows 凭据管理器，不写入 SQLite、页面响应、导出或日志。应用不会自动读取环境变量中的密钥。
- 模型服务地址要求 HTTPS；只有本机地址允许 HTTP。模型只返回结构化数据，不拥有浏览器操作、文件或任意工具权限。
- 网页内容始终视作不可信数据。应用不登录网站、不绕过验证码或访问控制、不点击网页按钮、不无限滚动、不扫描本机文件夹。
- 应用关闭了跨域访问，写操作校验本机 Host、Origin 和 CSRF 令牌。服务只监听回环地址。

## 采集边界和额度

- 仅支持公开 HTTP(S) 页面、公开文字 PDF 和用户主动粘贴的文字；不支持登录后内容、图片 OCR、音视频或批量本机文件。
- 会遵守 robots 规则与站点访问节奏；校验 DNS、重定向和浏览器子请求，拒绝本机、私网、链路本地和保留地址。
- 单个网页正文最多 10 MiB；PDF 最多 20 MiB、200 页，只提取可选择的文字。扫描版 PDF 会说明没有 OCR。
- 单个来源最多读取 5 页；一次运行最多 100 次文档读取和 20 次动态浏览器读取。
- 每轮最多 12 次搜索（首轮发现最多 8 个来源，最多补搜两轮、每轮最多 2 次），每日最多 60 次；模型每轮最多 40 次、每日最多 200 次。
- 输入 Token 每轮最多 120,000、每日最多 600,000；输出 Token 每轮最多 20,000、每日最多 100,000。计数按提供方 usage 或保守预留显示；服务未提供可信价格上界时不承诺精确费用封顶。
- 同一时刻最多一个运行；每轮主动运行最多 15 分钟，每天最多启动 20 轮。暂停、恢复和程序中断不会重置额度或时间。
- 来源失败时其他来源仍可继续；达到额度或时间上限会保存已有结果并标记为部分完成。中断时在途请求按已使用额度保留，结果未知的请求不会自动重新派发。

## 本机数据、备份与删除

数据库和来源快照位于：

```text
%LOCALAPPDATA%\NaturalLanguageInformationAssistant\assistant.sqlite3
```

应用默认保留原始来源快照 30 天，结果和必要摘录 180 天。原始快照清理后，摘录和来源链接可继续查看，但结果会标记为“证据已失效”，无法重新定位到完整原文。历史页支持删除任务及全部结果；任务页也可只清理原文并保留派生结果。备份前先停止应用，再复制整个数据目录；导出文件由浏览器下载到你的下载目录。

依赖固定版本记录在 `requirements.lock`。更新代码前备份本机数据目录；数据库启动时会按编号执行一次性迁移。

## 开发与验证

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check src tests
```

测试使用假搜索/模型服务、本地 HTTP 夹具和临时 SQLite；不会调用付费搜索或模型服务。浏览器集成测试需要本机 Microsoft Edge，或先运行 `python -m playwright install chromium`。
